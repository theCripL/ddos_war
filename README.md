1. Запустите DDos_war.bat
2. Нажмите [1] First Launch
3. Нажмите еще раз [1] и укажите токен вашего виджета DonationAlerts
4. После в этом же разделе нажмите [2] и укажите имя вашего Twitch канала
5. Вернитесь в основное меню и нажмите [3] для запуска локального сервера (нужно для работы интеграции с DA)
3. Добавьте index.html как Browser Source (Браузер) в OBS на всю сцену и включенной опцией «Обновлять браузер, когда сцена становится активной»
4. Используйте [2] для тестирования виджета

Команды для модераторов чата:
1. расходимся все — мгновенно прекращает и распускает все текущие активные митинги на экране. Участники митингов бросают транспаранты и продолжают движение
2. митинги запрещены — полностью блокирует возможность формирования новых митингов на стриме и немедленно разгоняет уже существующие
3. митинги разрешены — снимает запрет и снова позволяет зрителям объединяться в митинги при повторении одинаковых слов
4. комендантский час — включает или отключает виджет
